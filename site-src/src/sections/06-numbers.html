The numbers, and what they do not show

Agent File Optimizer does not make text smaller, and it does not claim to. It saves tokens where a file carries a lot of markup, and it turns files an agent cannot read at all into readable text. The value is orientation and readability, not compression. Each figure below is a receipt: what is claimed, when it holds, what it leaves out, and how to check it.
