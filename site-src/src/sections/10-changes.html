What has changed

  • Web pages are now read as documents, not stripped of tags, and EPUB books are read in their own order. Long files come over MCP in parts, so an agent does not lose the end.
  • Word, PowerPoint, Excel, and PDF files are now read from their structure, and checked against independent extractors.
  • Setup is a button or one command. The database tables create themselves on first use.
  • Opening a share link in a browser shows a readable page. Agents still receive the Markdown.
  • A workspace with no files yet explains that, instead of showing an error.
  • A blank admin token now refuses to create workspaces instead of leaving them open.
  • The page that creates links is protected against being framed, and input borders are easier to see.

The full list, by version, is in the changelog.
