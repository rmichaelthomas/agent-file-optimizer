## Generated files

`worker-configuration.d.ts` is generated by `wrangler types` and reflects the bindings in `wrangler.jsonc`.

## Assets

The public site uses no images, fonts, or scripts from third parties. Its styles are inline, and its system font stack is the reader's own.

The screenshot in `docs/images/` was captured from this project's own interface, using a local test workspace.

## Checking the list

Run `npm ls --omit=dev` to see the runtime tree, and `npm audit` to check for known advisories. The list here is maintained by hand, so update it when dependencies change.
