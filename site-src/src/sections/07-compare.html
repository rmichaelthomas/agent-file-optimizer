Alternatives

If you would otherwise do something else, what is different here
If you would otherwise…What is different here
Zip the folder and share a drive linkThe agent gets an orientation note and a manifest, not a bundle to unpack. The link ends by itself.
Paste files into a chatOriginals stay intact, paths are kept, and the same link works for several agents or sessions within the window.
Use a tool that flattens a repository into one promptThis takes mixed folders, not only repositories, and keeps the originals beside the readable text. It does not do private repositories.
Use a hosted file-sharing serviceYou run it, so the files sit in an account you control. The cost is that you have to deploy it.

Where the others still win: a hosted service needs no deployment, and a drive link has no 10 MiB limit on each file.
