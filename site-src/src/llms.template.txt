# Agent File Optimizer

> A self-hosted Cloudflare Worker that turns files into a temporary, readable link for an AI agent or a collaborator. You add files, a folder, or a public GitHub repository. The link keeps the originals and adds a handoff note and readable text. It stops working when the window you choose (1, 6, or 12 hours) ends or you revoke it, and the stored content is deleted. Open source under Apache-2.0. There is no hosted service; you run your own copy.

## What a share link contains

- `handoff.md`: what the workspace is for, when it expires, and what to read first.
- `manifest.json`: each file with its hash, parser, confidence, and warnings.
- `content.md` and `content.jsonl`: readable text and structured records.
- `tree.txt`: the folder layout.
- `original/<path>`: every file exactly as it was added.

## Limits stated plainly

- Reads text, Markdown, code, logs, JSON, CSV, TSV, HTML, EPUB, ZIP, DOCX, PPTX, XLSX, and PDF. PDFs are read in the order they were written. Images and scans are kept as originals with no text recognition.
- Each file is limited to 10 MiB. Private repositories are not supported.
- Not a malware scanner. A share link is a bearer link: anyone who has it can read the workspace until it ends.
- The read-only MCP endpoint is experimental and tested with a few clients.
