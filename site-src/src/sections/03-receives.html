What the agent receives

Open the link and the first thing you get is handoff.md, a plain-language orientation. A person who opens the same link in a browser sees it as a readable page. An agent, or curl, receives the Markdown.

What follows is a real sample: a two-row CSV and a one-line note, run through the project's own code. Every file below was printed by that code, not typed. Open any of them.

One file, read two ways

Each CSV row became a record that keeps its column names, and the note became one text record. content.md shows the same rows as a table. The CSV itself is untouched in original/data/people.csv. A file the project cannot read stays as an original and is flagged in the manifest, rather than being dropped or guessed at.
