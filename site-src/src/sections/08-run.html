How to use it

Try it on your computer

No account is needed and nothing leaves your machine. The database and bucket live in .wrangler/ on your computer.

git clone https://github.com/rmichaelthomas/agent-file-optimizer.git
cd agent-file-optimizer
npm install
npm run dev

Open the address Wrangler prints, drop in a file, and press Create temporary agent link.

Run your own copy on Cloudflare

Use the button, which needs a Cloudflare account and no terminal, or run npm run deploy from a clone. Either way the storage is created for you, and you set an admin token so strangers cannot create workspaces on your account. Without one, anyone who can reach your Worker can.

Deploy your own copy to Cloudflare

Connect an agent

Give the agent the share link and tell it to read handoff.md first. The link also exposes a read-only MCP endpoint for clients that support it. That endpoint is experimental.
