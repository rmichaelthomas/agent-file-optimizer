Open source · self-hosted · temporary

Hand files to an agent, then let them expire.

Agent File Optimizer turns a set of files into a temporary, readable workspace. You get one link. Whoever you share it with, human or agent, can read the originals and clear notes about them. When the window you chose ends, the link stops working and the content is deleted.

Deploy your own copy to Cloudflare Read the code on GitHub

There is no hosted service to sign up for. This project is software you run on your own Cloudflare account, or on your computer with no account at all. The maintainer's own deployment is private and needs an admin token to create links.

The life of a link

  1. You add files

    Files, a folder, or a public GitHub repository. You choose how long the link will work.

  2. The link works

    For 1, 6, or 12 hours. Anyone who has it can read the workspace, and nothing else.

    1 h 6 h 12 h

    The three windows, drawn to scale.

  3. The window ends

    The link answers 410 Gone from that moment. You can end it sooner by revoking it.

  4. The content is deleted

    On the next request, or within 15 minutes by a scheduled cleanup, which retries if a deletion fails.

How it works

Sharing a folder of mixed files with an agent usually means explaining each file, converting some of them, and remembering which copy is current. Agent File Optimizer does that preparation once. It keeps your originals, adds readable versions where it can, and gives you a link to share.

1

Add what to share

Drop in files, choose a folder, or paste the address of a public GitHub repository.

Done when you press Create temporary agent link.

2

Choose a window

Keep the link working for 1, 6, or 12 hours. You can also revoke it sooner.

Done when the link shows the time it will end.

3

Share the link

Copy the link and send it to the agent or person who needs the files.

Tell the agent to read handoff.md first.

Who it is for: people who want a simple handoff to an agent or a collaborator, without remembering conversion commands, copying files around, or trusting a service with more than the window needs.

What the agent receives

Open the link and the first thing you get is handoff.md, a plain-language orientation. A person who opens the same link in a browser sees it as a readable page. An agent, or curl, receives the Markdown.

What follows is a real sample: a two-row CSV and a one-line note, run through the project's own code. Every file below was printed by that code, not typed. Open any of them.

Limits at a glance

Each file
10 MiB.
Each request
200 files and 50 MiB.
Public GitHub repository
Public repositories on github.com only, with a 25 MiB archive cap.
Spreadsheets
A sheet stops at 5,000 rows.
Long books and pages
Reading stops at 1.5 million characters and says how far it got.
PDF and Office files on Cloudflare's free plan
Reading them takes real CPU time. The free Workers plan allows 10 ms per request, which small documents can fit and larger ones will not. On that plan, set DOCUMENT_READING=off and they are kept as originals.
Request rate
120 requests a minute per caller address. Cloudflare's limiter is approximate, so this is a brake on floods, not an exact cap.

It is not a malware scanner. It runs a small set of heuristic checks and labels them that way. Do not treat them as a malware verdict. There is no text recognition for scanned pages and pictures.

When the window ends

The clock is the point of the project, so this is the part to read closely.

What changes when the window ends

While the window is open

  • The share link can read: handoff.md, the manifest, the readable text, and your originals, as many times as needed.
  • The separate upload token can add files and revoke the link. The share link cannot.
  • The read-only MCP endpoint on the link answers. It is experimental.

After it ends, or once you revoke it

  • Every request returns 410 Gone at once, because the app checks expiry on every request. That includes the MCP endpoint.
  • The stored files and records are deleted on the next request or within 15 minutes, by the scheduled cleanup.

If you revoke the link, or a deletion fails

  1. You revoke the link. Access returns 410 Gone at once.
  2. The app deletes the file rows and every stored object before it reports success.
  3. If a deletion fails partway, access stays off, the workspace is marked as not yet purged, and the response to revoke says so.
  4. The next revoke or the scheduled cleanup retries until the purge completes.

What is not covered. Your hosting provider's own backups, logs, and retention policies sit outside the app, and the project does not promise secure erasure. "Zero retention" is a design goal, not a guarantee. Parsing runs inside your Worker, with no external processing by default. The full version is in PRIVACY.md.

The numbers, and what they do not show

Agent File Optimizer does not make text smaller, and it does not claim to. It saves tokens where a file carries a lot of markup, and it turns files an agent cannot read at all into readable text. The value is orientation and readability, not compression. Each figure below is a receipt: what is claimed, when it holds, what it leaves out, and how to check it.

Where it saves tokens

Ten real web pages: 91% fewer tokens

Claim
On ten real web pages, the readable text came to 91% fewer tokens than the page's markup (583,220 tokens down to 49,899).
Holds when
The ten pages were fetched live on 28 Oct 2026 and counted with a proxy tokenizer (o200k_base). They are modern, script-heavy pages, and the saving ranged from 71% to 99%.
Doesn't tell you
Older, plainer HTML will save less. A proxy tokenizer is not Claude's, so read the figure as indicative. Ten pages is a small sample, so this is not a general saving.
Check it
The report: BENCHMARKS.md
python3 scripts/benchmark/pages.py fetch DIR
EVAL_IN=DIR EVAL_OUT=OUT npx vitest run tests/extraction-dump.test.ts
python3 scripts/benchmark/pages.py measure DIR OUT

Where it does not

Plain text and code: no saving

Claim
Leaving out the one HTML page, the readable notes for the text, Markdown, code, JSON and CSV files came to 23,073 tokens against 22,344 for the originals, which is 3% more.
Holds when
A 15-file corpus built from the repository's own files and prose, measured on 27 Oct 2026 with a proxy tokenizer.
Doesn't tell you
It saves tokens only where a file carries markup. On text and code the value is orientation and readability, not compression, and the handoff note itself adds 255 tokens. The corpus is small.

How to use it

Try it on your computer

No account is needed and nothing leaves your machine. The database and bucket live in .wrangler/ on your computer.

git clone https://github.com/rmichaelthomas/agent-file-optimizer.git
cd agent-file-optimizer
npm install
npm run dev

Open the address Wrangler prints, drop in a file, and press Create temporary agent link.

Run your own copy on Cloudflare

Use the button, which needs a Cloudflare account and no terminal, or run npm run deploy from a clone. Either way the storage is created for you, and you set an admin token so strangers cannot create workspaces on your account. Without one, anyone who can reach your Worker can.

Questions people ask

What is Agent File Optimizer?

It is a small open-source Cloudflare Worker. You add files, a folder, or a public GitHub repository, and it gives you one temporary link. Whoever has the link, a person or an AI agent, can read the original files and a plain-language handoff note about them. When the window you chose ends, the link stops working and the stored content is deleted.

Is there a hosted version I can sign up for?

No. The project is software you run on your own Cloudflare account, and the maintainer does not offer a hosted service. You can deploy a copy with one button, or run it on your own computer with no account at all.

How long does a link last?

You choose one, six, or twelve hours when you create it, and you can revoke it sooner. After that the link returns an error and the app deletes the stored files and records. If a deletion fails, a scheduled cleanup retries it.

Which file types does it read?

Text, Markdown, code, logs, JSON, CSV, TSV, HTML, EPUB books, ZIP archives, Word, PowerPoint, Excel, and PDF files are read. Office files keep their headings, lists, tables, slides, notes, and sheets. PDFs are read in the order they were written, so columns can interleave. Scanned PDFs and images are kept as originals with a warning, because there is no text recognition built in. Each file is limited to 10 MiB.

Does it scan files for malware?

No. It runs a few simple heuristic checks and labels them as such. Do not treat them as a malware verdict.

How private is a share link?

A share link is a bearer link: anyone who has it can read the workspace until it ends, so treat it like a password. The app stores only hashes of its tokens, and its own logs never include them. Your hosting provider's backups and account-level logs are outside the app's control, and the project does not promise secure erasure.

Does it work with MCP?

The share link also exposes a read-only MCP endpoint. It is experimental. It has been tested with the official TypeScript and Python SDKs and with Claude Code.

What does it cost?

The software is free under the Apache License 2.0. The workspaces run in your own Cloudflare account, so Cloudflare's pricing for Workers, R2, and D1 applies to your usage.

What has changed

  • Web pages are now read as documents, not stripped of tags, and EPUB books are read in their own order. Long files come over MCP in parts, so an agent does not lose the end.
  • Word, PowerPoint, Excel, and PDF files are now read from their structure, and checked against independent extractors.
  • Setup is a button or one command. The database tables create themselves on first use.
  • Opening a share link in a browser shows a readable page. Agents still receive the Markdown.
  • A workspace with no files yet explains that, instead of showing an error.
  • A blank admin token now refuses to create workspaces instead of leaving them open.
  • The page that creates links is protected against being framed, and input borders are easier to see.

The full list, by version, is in the changelog.
