Open source · self-hosted · temporary

Hand files to an agent, then let them expire.

Agent File Optimizer turns a set of files into a temporary, readable workspace. You get one link. Whoever you share it with, human or agent, can read the originals and clear notes about them. When the window you chose ends, the link stops working and the content is deleted.

Deploy your own copy to Cloudflare Read the code on GitHub

There is no hosted service to sign up for. This project is software you run on your own Cloudflare account, or on your computer with no account at all. The maintainer's own deployment is private and needs an admin token to create links.

The life of a link

  1. You add files

    Files, a folder, or a public GitHub repository. You choose how long the link will work.

  2. The link works

    For 1, 6, or 12 hours. Anyone who has it can read the workspace, and nothing else.

    1 h 6 h 12 h

    The three windows, drawn to scale.

  3. The window ends

    The link answers 410 Gone from that moment. You can end it sooner by revoking it.

  4. The content is deleted

    On the next request, or within 15 minutes by a scheduled cleanup, which retries if a deletion fails.
