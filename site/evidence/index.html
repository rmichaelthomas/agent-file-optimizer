The files behind the numbers

Every figure on the project page comes from the report below. It is a byte-for-byte copy of a file in the repository, listed with its size and SHA-256. Check a hash with shasum -a 256 FILE. The measurements describe named workloads on one date; read each report's own limits before you rely on a number.
